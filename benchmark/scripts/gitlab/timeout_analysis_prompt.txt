For each timed-out trial, determine the root cause and classify it into exactly one of these categories:

2. **Agent loop** — The agent was stuck repeating the same actions. Evidence: repeated_patterns show consecutive_repeat or frequent_repeat with count >= 3. The agent was not making progress toward the task.
